### Demo & Feedback

- 💡 **Demo & Feedback**: Reibungslosere Nutzung der öffentlichen Online-Demo und verständliche Hinweise beim Abgeben von Feedback.
- 📬 **Feedback von Self-Hosted-Instanzen**: Selbstgehostete Instanzen leiten Feedback-Meldungen jetzt standardmäßig transparent über einen zentralen Relay an das GitHub-Repository weiter, ohne dass Betreiber:innen einen eigenen GitHub-Token anlegen müssen. Im Administrationsbereich erläutern neue Info-Popovers und Hilfebereiche das Zusammenspiel und warnen vor Fehlkonfigurationen.
- 🐙 **Auf GitHub öffnen & Rückfrage-Kontakt**: Im Feedback-Dialog kann optional eine E-Mail-Adresse für Rückfragen angegeben werden. Zudem lassen sich Meldungen vor dem Absenden direkt mit vorausgefülltem Titel und Text auf GitHub öffnen.
- 📅 **Dynamische Demo-Reisedaten**: Die Demo zeigt bei jedem Besuch automatisch einen Urlaub in der nahen Zukunft an, statt veraltete Datumsstände aus vorherigen Besuchen dauerhaft im Browser zu halten.
