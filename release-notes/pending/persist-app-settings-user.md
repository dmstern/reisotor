# Persistieren der App-Einstellungen pro User

- Die App-Einstellungen (Erscheinungsbild/Dark Mode, Farbakzente, Rahmendicke, Glassmorphism, Navigation, Dashboard-Kacheln, Kalender-Format, Wettermodell und Heimatwährung) werden nun am User-Datensatz im Backend persistiert und geräteübergreifend synchronisiert.
