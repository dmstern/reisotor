# Project: Reisotor Apple-Style Scrollytelling Landing Page

## Architecture

- **Tech Stack**: Vue 3 + Vite + TypeScript (frontend), Fastify + better-sqlite3 (backend), Playwright (E2E & baseline screenshot tooling).
- **Entry Points**:
  - `frontend/landing.html` & `frontend/src/landing-main.ts` -> mounts `LandingView.vue` standalone with `style.css`.
  - `package.json` script `npm run build:landing` -> builds standalone landing distribution.
  - `package.json` script `npm run generate:screenshots` -> builds backend & frontend and runs `e2e/tests/tools/generate-baseline-screenshots.manual.spec.ts`.
- **Image Assets**:
  - `docs/screenshots/` -> raw baseline screenshots generated by Playwright.
  - `frontend/public/landing/` -> optimized screenshot assets consumed by `LandingView.vue`.
  - Sync script: `copy_screenshots.sh` (or automated sync within pipeline).

## Interface Contracts

### Screenshots ↔ Landing Page

- Generated screenshot files in `frontend/public/landing/`:
  - `screenshot-dashboard-light.png`, `screenshot-dashboard-dark.png`
  - `screenshot-spots-light.png`, `screenshot-spots-dark.png` (or `screenshot-tour-*`)
  - `screenshot-budget-light.png`, `screenshot-budget-dark.png`
  - `screenshot-lists-light.png`, `screenshot-lists-dark.png` (or `screenshot-packing-*`)
- Calendar view visible ONLY in `screenshot-dashboard-*`.
- Tour view (spots, dashed line SVG, linearGradient) visible in `screenshot-spots-*` / `screenshot-tour-*`.

### Robot Component ↔ Landing Hero

- Component: `frontend/src/components/ReisotorRobot.vue`
- Prop: `phase="pack"` (or `'packing'`), `size="240px"`, no `variant="circle"` (defaults to `'blank'`).
